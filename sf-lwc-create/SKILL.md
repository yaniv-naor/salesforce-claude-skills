# SF LWC Create

Creates Lightning Web Components with complete structure including HTML, JavaScript, CSS, metadata, optional Apex controller, and Jest tests. **Works with any Salesforce project.**

## When to Use

- Creating new Lightning Web Components
- Building interactive UI elements
- Creating data display components
- Building forms or custom input controls
- Integrating with Apex backend

## Instructions

### Step 1: Detect Project Prefix

Use `sf-prefix-detect` skill to determine the project prefix.

**LWC prefix format:**
- Project prefix: `[PREFIX]_` (uppercase) → e.g., `ABC_`, `PROJ_`
- LWC prefix: `[prefix]_` (lowercase) → e.g., `rtn_`, `proj_`

**Transformation:**
```
ABC_ → rtn_
XYZ_ → xyz_
DEF_ → gcr_
MYPROJECT_ → myproject_
```

### Step 2: Gather Information

Ask user for (or infer from request):

**Required:**
- **Component name** (without prefix, camelCase) - e.g., `documentViewer`, `customForm`
- **Component purpose** - Brief description of what it does
- **Needs Apex controller?** (Yes/No)

**Optional:**
- Specific features: data table, form, modal, card, etc.
- Lightning modules needed: `ui-record-api`, `ui-list-api`, `navigation`, etc.
- Target pages: App Page, Record Page, Home Page
- Supported objects (for Record Pages)

**Auto-detected:**
- Component folder: `[prefix]_[componentName]` (e.g., `proj_documentViewer`)
- JavaScript class: `[PrefixComponentName]` in PascalCase (e.g., `ProjDocumentViewer`)
- Apex controller: `[PREFIX]_[ComponentName]Ctrl` (e.g., `PROJ_DocumentViewerCtrl`)
- HTML tag: `<c-[prefix]-[component-name]>` (kebab-case)

### Step 3: Create Component Structure

Generate complete LWC folder structure:

```
force-app/main/default/lwc/
└── [prefix]_[componentName]/
    ├── [prefix]_[componentName].html        ← Template
    ├── [prefix]_[componentName].js          ← JavaScript controller
    ├── [prefix]_[componentName].css         ← Styles
    ├── [prefix]_[componentName].js-meta.xml ← Metadata
    └── __tests__/
        └── [prefix]_[componentName].test.js ← Jest tests
```

**With Apex Controller (using @wire):**
```javascript
// Generated by Claude Code on [YYYY-MM-DD]
import { LightningElement, api, wire } from 'lwc';
import { ShowToastEvent } from 'lightning/platformShowToastEvent';
import getData from '@salesforce/apex/[PREFIX]_[ComponentName]Ctrl.getData';
import saveData from '@salesforce/apex/[PREFIX]_[ComponentName]Ctrl.saveData';

export default class [PrefixComponentName] extends LightningElement {
    @api recordId;
    data;
    error;
    
    /**
     * Wire Apex method to automatically fetch data
     */
    @wire(getData, { recordId: '$recordId' })
    wiredData({ error, data }) {
        if (data) {
            this.data = data;
            this.error = undefined;
        } else if (error) {
            this.error = error;
            this.data = undefined;
            this.showToast('Error', error.body?.message, 'error');
        }
    }
    
    /**
     * Handle save button click
     */
    handleSave() {
        saveData({ recordId: this.recordId, data: this.data })
            .then(result => {
                this.showToast('Success', 'Data saved successfully', 'success');
            })
            .catch(error => {
                this.showToast('Error', error.body?.message, 'error');
            });
    }
    
    showToast(title, message, variant) {
        this.dispatchEvent(new ShowToastEvent({ title, message, variant }));
    }
}
```

## LWC Best Practices

### Naming Conventions

| Element | Format | Example |
|---------|--------|---------|
| Folder | `[prefix]_[camelCase]` | `proj_documentViewer` |
| JavaScript Class | `[PrefixPascalCase]` | `ProjDocumentViewer` |
| HTML Tag | `<c-[prefix]-[kebab-case]>` | `<c-proj-document-viewer>` |
| Apex Controller | `[PREFIX]_[PascalCase]Ctrl` | `PROJ_DocumentViewerCtrl` |

### Performance Optimization

**Use @wire for reactive data:**
```javascript
@wire(getData, { recordId: '$recordId' })
wiredData({ error, data }) {
    // Automatically refreshes when recordId changes
}
```

**Cache read-only Apex methods:**
```apex
@AuraEnabled(cacheable=true)
public static List<SObject> getData(Id recordId) {
    // Cached on client side
}
```

**Lazy load data:**
```javascript
connectedCallback() {
    // Only load data when component is actually rendered
    this.loadData();
}
```

**Minimize DOM updates:**
```javascript
// Bad: Multiple DOM updates
this.field1 = value1;
this.field2 = value2;
this.field3 = value3;

// Good: Batch updates
this.updateFields({ field1: value1, field2: value2, field3: value3 });
```

### Error Handling

**Always handle Apex errors:**
```javascript
apexMethod({ param: value })
    .then(result => {
        // Handle success
    })
    .catch(error => {
        // Handle error
        this.showToast('Error', error.body?.message || 'Unknown error', 'error');
    });
```

**Use @wire error handling:**
```javascript
@wire(getData, { recordId: '$recordId' })
wiredData({ error, data }) {
    if (error) {
        this.error = error;
        this.showToast('Error', error.body?.message, 'error');
    }
}
```

**Throw AuraHandledException in Apex:**
```apex
@AuraEnabled
public static String saveData(Id recordId) {
    try {
        // Logic
    } catch (Exception e) {
        throw new AuraHandledException(e.getMessage());
    }
}
```

### Security

**Use `WITH USER_MODE` in SOQL:**
```apex
List<Account> accounts = [
    SELECT Id, Name FROM Account
    WITH USER_MODE
];
```

**Use `AccessLevel.USER_MODE` in DML:**
```apex
Database.update(records, AccessLevel.USER_MODE);
```

**Validate user input:**
```javascript
handleSave() {
    if (!this.validateInput()) {
        this.showToast('Error', 'Please fill all required fields', 'error');
        return;
    }
    // Proceed with save
}
```

## Troubleshooting

### Issue: Component not visible in App Builder

**Solution:**
1. Check `isExposed` is `true` in metadata
2. Verify `<targets>` include desired page type
3. Deploy component: `sf project deploy start -d force-app/main/default/lwc`
4. Refresh App Builder page

### Issue: Apex method not found

**Solution:**
1. Verify import path: `@salesforce/apex/ClassName.methodName`
2. Check method has `@AuraEnabled` annotation
3. Deploy Apex class first
4. Use correct class name (with prefix)

### Issue: Jest tests failing

**Solution:**
1. Check mock data structure matches expectations
2. Verify DOM cleanup in `afterEach`
3. Use `await Promise.resolve()` for async updates
4. Mock Apex methods properly

### Issue: CSS not applying

**Solution:**
1. Use `:host` for component-level styles
2. Verify SLDS utility classes are correct
3. Check Shadow DOM boundaries
4. Use `::slotted()` for slotted content

### Issue: @wire not updating

**Solution:**
1. Ensure property is reactive: `{ recordId: '$recordId' }`
2. Check Apex method is `cacheable=true`
3. Verify field-level security on queried fields
4. Use `refreshApex()` to manually refresh
