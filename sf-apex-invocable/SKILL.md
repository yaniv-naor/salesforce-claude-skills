# SF Apex Invocable

Creates Invocable Methods that can be called from Salesforce Flows with proper Request/Response structure and error handling. **Works with any Salesforce project.**

## When to Use

- Creating Flow actions (callable from Flow Builder)
- Building reusable logic for Screen Flows
- Creating custom actions for Record-Triggered Flows
- Enabling Flow to call complex Apex logic
- Integrating external systems via Flow

## Instructions

### Step 1: Detect Project Prefix

Use `sf-prefix-detect` skill to determine the project prefix.

**Invocable Method naming:**
- Class: `[PREFIX]_[ActionName]Invocable`
- Example: `PROJ_SendEmailInvocable`, `ABC_ProcessDocumentInvocable`

### Step 2: Gather Information

Ask user for (or infer from request):

**Required:**
- **Action name** (without prefix, PascalCase) - e.g., `SendEmail`, `ProcessDocument`
- **Purpose** - What does this action do?
- **Input parameters** - What data comes from Flow?
- **Output parameters** - What data returns to Flow?

**Optional:**
- **Needs callout?** - HTTP callouts to external systems
- **Category** - Group actions in Flow Builder (e.g., "Integration", "Validation")
- **Description** - Detailed description for Flow Builder

**Auto-detected:**
- Class name: `[PREFIX]_[ActionName]Invocable`
- Request class: `Request`
- Response class: `Response`

/**
 * Invocable method for [Purpose]
 * Can be called from Flow Builder as a custom action
 */
public with sharing class [PREFIX]_[ActionName]Invocable {
    
    /**
     * Execute [action description]
     * @param requests List of request parameters from Flow
     * @return List of response objects with results
     */
    @InvocableMethod(
        label='[Action Label for Flow Builder]'
        description='[Detailed description shown in Flow Builder]'
        category='[Category]'
    )
    public static List<Response> execute(List<Request> requests) {
        List<Response> responses = new List<Response>();
        
        // Collect all data for bulkification
        Set<Id> allRecordIds = new Set<Id>();
        for (Request req : requests) {
            if (req.recordId != null) {
                allRecordIds.add(req.recordId);
            }
        }
        
        // Query once (SOQL outside loop)
        Map<Id, SObject> recordsById = new Map<Id, SObject>();
        if (!allRecordIds.isEmpty()) {
            recordsById = new Map<Id, SObject>([
                SELECT Id, Name
                FROM [Object]
                WHERE Id IN :allRecordIds
                WITH USER_MODE
            ]);
        }
        
        // Process each request
        for (Request req : requests) {
            Response res = new Response();
            
            try {
                // Validate input
                if (req.recordId == null) {
                    throw new IllegalArgumentException('Record Id is required');
                }
                
                // Get record
                SObject record = recordsById.get(req.recordId);
                if (record == null) {
                    throw new IllegalArgumentException('Record not found');
                }
                
                // TODO: Implement business logic
                
                // Set success response
                res.isSuccess = true;
                res.message = 'Operation completed successfully';
                
            } catch (Exception e) {
                // Handle errors gracefully
                res.isSuccess = false;
                res.errorMessage = e.getMessage();
                res.errorType = e.getTypeName();
            }
            
            responses.add(res);
        }
        
        return responses;
    }

     */
    public class Request {
        @InvocableVariable(
            label='Record Id'
            description='Id of the record to process'
            required=true
        )
        public Id recordId;
        
        @InvocableVariable(
            label='Additional Parameter'
            description='Optional additional parameter'
            required=false
        )
        public String additionalParam;
        
        // Add more input variables as needed

     * Response wrapper for Flow output parameters
     */
    public class Response {
        @InvocableVariable(
            label='Success'
            description='Indicates if operation was successful'
        )
        public Boolean isSuccess;
        
        @InvocableVariable(
            label='Message'
            description='Success message or additional information'
        )
        public String message;
        
        @InvocableVariable(
            label='Error Message'
            description='Error message if operation failed'
        )
        public String errorMessage;
        
        @InvocableVariable(

// Generated by Claude Code on 2026-05-05
/**
 * Invocable method for sending custom emails
 * Can be called from Flow Builder to send emails with custom templates
 */
public with sharing class PROJ_SendEmailInvocable {
    
    @InvocableMethod(
        label='Send Custom Email'
        description='Sends a custom email to specified recipients with template'
        category='Communication'
    )
    public static List<Response> execute(List<Request> requests) {
        List<Response> responses = new List<Response>();
        
        // Collect email messages for bulk send
        List<Messaging.SingleEmailMessage> emails = new List<Messaging.SingleEmailMessage>();
        
        for (Request req : requests) {
            Response res = new Response();
            
            try {
                // Validate input
                if (String.isBlank(req.recipientEmail)) {
                    throw new IllegalArgumentException('Recipient email is required');
                }
                if (String.isBlank(req.subject)) {
                    throw new IllegalArgumentException('Subject is required');
                }
                if (String.isBlank(req.body)) {
                    throw new IllegalArgumentException('Email body is required');
                }
                
                // Create email message
                Messaging.SingleEmailMessage email = new Messaging.SingleEmailMessage();
                email.setToAddresses(new String[]{ req.recipientEmail });
                email.setSubject(req.subject);
                email.setPlainTextBody(req.body);
                
                // Add optional CC
                if (!String.isBlank(req.ccEmail)) {
                    email.setCcAddresses(new String[]{ req.ccEmail });
                }
                
                // Add to bulk list
                emails.add(email);
                
                // Set success response
                res.isSuccess = true;
                res.message = 'Email queued successfully';
                res.recipientEmail = req.recipientEmail;
                
            } catch (Exception e) {
                res.isSuccess = false;
                res.errorMessage = e.getMessage();
                res.errorType = e.getTypeName();
            }
            
            responses.add(res);
        }
        
        // Send all emails at once (bulkified)
        if (!emails.isEmpty()) {
            try {
                Messaging.SendEmailResult[] results = Messaging.sendEmail(emails);
                
                // Update responses with send results
                for (Integer i = 0; i < results.size(); i++) {
                    if (!results[i].isSuccess()) {
                        responses[i].isSuccess = false;
                        responses[i].errorMessage = results[i].getErrors()[0].getMessage();
                    }
                }
            } catch (Exception e) {
                // Handle bulk send errors
                for (Response res : responses) {
                    if (res.isSuccess) {
                        res.isSuccess = false;
                        res.errorMessage = 'Email send failed: ' + e.getMessage();
                    }
                }
            }
        }
        
        return responses;
    }
    
    public class Request {
        @InvocableVariable(label='Recipient Email' required=true)
        public String recipientEmail;
        
        @InvocableVariable(label='Subject' required=true)
        public String subject;
        
        @InvocableVariable(label='Email Body' required=true)
        public String body;
        
        @InvocableVariable(label='CC Email' required=false)
        public String ccEmail;
    }
    
    public class Response {
        @InvocableVariable(label='Success')
        public Boolean isSuccess;
        
        @InvocableVariable(label='Message')
        public String message;
        
        @InvocableVariable(label='Recipient Email')
        public String recipientEmail;
        
        @InvocableVariable(label='Error Message')
        public String errorMessage;
        
        @InvocableVariable(label='Error Type')
        public String errorType;
    }
}

// Generated by Claude Code on 2026-05-05
/**
 * Invocable method for calling external API
 * Integrates with external system via HTTP callout
 */
public with sharing class PROJ_CallExternalAPIInvocable {
    
    @InvocableMethod(
        label='Call External API'
        description='Makes HTTP callout to external system and returns response'
        category='Integration'
        callout=true
    )
    public static List<Response> execute(List<Request> requests) {
        List<Response> responses = new List<Response>();
        
        for (Request req : requests) {
            Response res = new Response();
            
            try {
                // Validate input
                if (String.isBlank(req.endpoint)) {
                    throw new IllegalArgumentException('Endpoint URL is required');
                }
                
                // Make HTTP callout
                HttpRequest httpReq = new HttpRequest();
                httpReq.setEndpoint(req.endpoint);
                httpReq.setMethod(req.method != null ? req.method : 'GET');
                httpReq.setTimeout(120000); // 2 minutes
                
                // Add body if provided
                if (!String.isBlank(req.requestBody)) {
                    httpReq.setBody(req.requestBody);
                    httpReq.setHeader('Content-Type', 'application/json');
                }
                
                // Send request
                Http http = new Http();
                HttpResponse httpRes = http.send(httpReq);
                
                // Parse response
                res.isSuccess = httpRes.getStatusCode() >= 200 && httpRes.getStatusCode() < 300;
                res.statusCode = httpRes.getStatusCode();
                res.responseBody = httpRes.getBody();
                res.message = res.isSuccess ? 'API call successful' : 'API call failed';
                
            } catch (Exception e) {
                res.isSuccess = false;
                res.errorMessage = e.getMessage();
                res.errorType = e.getTypeName();
            }
            
            responses.add(res);
        }
        
        return responses;
    }
    
    public class Request {
        @InvocableVariable(label='Endpoint URL' required=true)
        public String endpoint;
        
        @InvocableVariable(label='HTTP Method' required=false)
        public String method; // GET, POST, PUT, DELETE
        
        @InvocableVariable(label='Request Body' required=false)
        public String requestBody;
    }
    
    public class Response {
        @InvocableVariable(label='Success')
        public Boolean isSuccess;
        
        @InvocableVariable(label='Message')
        public String message;
        
        @InvocableVariable(label='Status Code')
        public Integer statusCode;
        
        @InvocableVariable(label='Response Body')
        public String responseBody;
        
        @InvocableVariable(label='Error Message')
        public String errorMessage;
        
        @InvocableVariable(label='Error Type')
        public String errorType;
    }
}

        label='Validate Record'

        category='Validation'
    )

        List<Response> responses = new List<Response>();
        
        // Collect record IDs for bulkification
        Set<Id> recordIds = new Set<Id>();
        for (Request req : requests) {
            if (req.recordId != null) {
                recordIds.add(req.recordId);
            }
        }
        
        // Query records once
        Map<Id, Account> accountsById = new Map<Id, Account>([
            SELECT Id, Name, BillingCountry, BillingState, BillingCity, BillingStreet
            FROM Account
            WHERE Id IN :recordIds
            WITH USER_MODE
        ]);
        
        // Validate each request
        for (Request req : requests) {
            Response res = new Response();
            List<String> validationErrors = new List<String>();
            
            try {
                // Get record
                Account acc = accountsById.get(req.recordId);
                if (acc == null) {
                    throw new IllegalArgumentException('Account not found');
                }
                
                // Validation 1: Required fields
                if (String.isBlank(acc.Name)) {
                    validationErrors.add('Name is required');

## Critical Rules & Best Practices

### @InvocableMethod Requirements

**Method signature must be:**
```apex
@InvocableMethod(...)
public static List<Response> methodName(List<Request> requests)
```

- ✅ Must be `public static`
- ✅ Must accept `List<T>` parameter
- ✅ Must return `List<T>`
- ❌ Cannot be instance method
- ❌ Cannot accept single object (must be list)

### @InvocableVariable Requirements

**Supported types:**
- ✅ Primitives: String, Integer, Boolean, Decimal, Double, Long
- ✅ Id, Date, DateTime, Time
- ✅ SObject and specific SObject types
- ✅ List<T> of supported types
- ❌ Map (not supported)
- ❌ Set (not supported)
- ❌ Custom Apex classes (except Request/Response)

### Bulkification

**Always design for bulk:**
```apex
// ❌ BAD: Query inside loop
for (Request req : requests) {
    List<Account> accounts = [SELECT Id FROM Account WHERE Id = :req.recordId];
}

// ✅ GOOD: Query once outside loop
Set<Id> recordIds = new Set<Id>();
for (Request req : requests) {
    recordIds.add(req.recordId);
}
Map<Id, Account> accountsById = new Map<Id, Account>([
    SELECT Id FROM Account WHERE Id IN :recordIds
]);
```

### Error Handling

**Return errors in Response (recommended):**
```apex
try {
    // Logic
    res.isSuccess = true;
} catch (Exception e) {
    res.isSuccess = false;
    res.errorMessage = e.getMessage();
    res.errorType = e.getTypeName();
}
```

**Throwing exception triggers Flow fault path:**
- Reserve for unrecoverable errors
- Most errors should be returned in Response

### Callout Support

**If method makes HTTP callouts:**
```apex
@InvocableMethod(
    label='Call API'
    callout=true  // Required for callouts!
)
```

## Troubleshooting

### Error: Method must be static

**Error:** `Methods with the InvocableMethod annotation must be static`

**Solution:** Add `static` keyword to method

### Error: List parameter required

**Error:** `InvocableMethod must have a List parameter`

**Solution:** Change parameter from `Request` to `List<Request>`

### Error: Unsupported variable type

**Error:** `InvocableVariable does not support Map type`

**Solution:** Use List or primitive types only

### Error: Callout not allowed

**Error:** `Callout not allowed from this context`

**Solution:** Add `callout=true` to @InvocableMethod annotation

### Error: Cannot find action in Flow

**Cause:** Class not deployed or label not matching

**Solution:**
1. Deploy class to org
2. Refresh Flow Builder
3. Search by exact label
4. Check category filter

## Reference

### @InvocableMethod Parameters

| Parameter | Required | Description |
|-----------|----------|-------------|
| `label` | ✅ Yes | Display name in Flow Builder |
| `description` | No | Detailed description shown in Flow Builder |
| `category` | No | Groups actions (e.g., "Integration", "Validation") |
| `callout` | No | Set `true` if method makes HTTP callouts |

### @InvocableVariable Parameters

| Parameter | Required | Description |
|-----------|----------|-------------|
| `label` | ✅ Yes | Display name in Flow Builder |
| `description` | No | Help text for Flow builders |
| `required` | No | `true` = Flow Builder marks as required |

### Common Response Fields

| Field | Type | Purpose |
|-------|------|---------|
| `isSuccess` | Boolean | Overall operation success |
| `message` | String | Success message or info |
| `errorMessage` | String | Error details if failed |
| `errorType` | String | Exception type (`e.getTypeName()`) |
